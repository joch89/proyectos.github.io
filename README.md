# Portafolio — José Chamorro

Sitio estático para GitHub Pages. Dos líneas de proyectos: GRD (grupos relacionados por el diagnóstico) y visión por computador.

## Archivos

- `index.html` — inicio
- `grd.html` — línea GRD
- `vision.html` — línea de visión por computador
- `style.css` — hoja de estilos compartida

## Publicar

1. Subir estos archivos a la raíz del repositorio.
2. Settings → Pages → Source: *Deploy from a branch*, rama `main`, carpeta `/ (root)`.
